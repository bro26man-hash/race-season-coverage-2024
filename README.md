# Race Season Coverage

Comprehensive race season coverage project with technical cornering analysis, multimedia assets, and data resources for motorsport journalism.

## Overview

This repository contains all materials for producing in-depth race season coverage, with a focus on the technical and physical aspects of motorsport. The project integrates technical reference notes, multimedia assets, and structured data to support high-quality journalistic output.

## Folder Structure

- **articles/** — Written coverage including technical analysis pieces, race reports, and reference notes
  - **technical-notes/** — Physics and engineering reference materials (G-force, cornering dynamics, etc.)
- **multimedia/** — Images, videos, diagrams, and other visual assets
- **data/** — Race data, telemetry references, statistics, and datasets

## Technical Focus: Cornering Physics

A key area of coverage is the physics of cornering, including:
- Lateral G-loads through corners
- Centripetal acceleration and its relationship to speed and radius
- The role of aerodynamic downforce in generating cornering grip
- Physical demands on drivers under sustained G-loading

See `articles/technical-notes/cornering-physics.md` for a detailed reference summary derived from Wikipedia's G-force article.

## Sources

Technical reference material sourced from Wikipedia's articles on G-force and related physics concepts.

## Getting Started

Browse the folders above for articles, multimedia assets, and data files. The technical notes in `articles/technical-notes/` provide a ready reference for writing about cornering physics and driver physical demands.
